# Scoring is data, with Sessions as their own records

Premier-category scoring changed many times (seven points tables, fifteen dropped-score periods, a 1949-only Fastest-lap bonus, the 2023 Sprint), so a Season's Scoring rule is data, not code. A Scoring rule holds a points table per Session type, a Fastest-lap bonus, and one or more Counting windows (a range of Rounds and how many Round scores count from it) instead of a single best-N, because 1976 counted the best 3 of the first 5 Rounds plus the best 3 of the last 5. Each Scoring rule records the source it was verified against, and Seasons with an unverified rule are not published. Verified means a cited source states the rule and the Replay's final Standings reproduce the official final table; a later hand check against motogp.com and the FIM can correct a rule, but does not hold back publishing.

Sessions are records of their own inside a Round, carrying their type, order, date and a points multiplier, rather than a label on each Result. Half points (1989 Belgium; today's rule for races stopped before half distance) apply to a whole Session, so they are that multiplier; a per-Result points override is reserved for anomalies affecting one Rider, such as a penalty. A new points-paying Session type (say, qualifying) needs only a new type and a points table, and automatically becomes a Replay Step.
