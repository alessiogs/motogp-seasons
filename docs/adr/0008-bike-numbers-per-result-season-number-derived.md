# Bike numbers are stored per Result; Season number is derived

A Bike number is stored on each Result, not once per Rider per Season, because in some eras (1976, for one) Riders changed numbers between Rounds, and even in fixed-number eras there are one-off exceptions (Capirossi's 58 at his last Round). The Season number shown in the Standings is derived: the number on more than half of a Rider's Results. A Season shows Season numbers only when every Result has a Bike number and every Rider has a majority number; otherwise numbers appear only in Classifications.

## Considered Options

- One number per Rider per Season, with exceptions recorded separately: less data, but wrong for per-event eras and needs a second mechanism for exceptions.
- A hand-set per-Season flag for "fixed numbers": explicit, but one more fact to keep in sync with the Results that already show it.

## Consequences

The rule is visible to readers on the site's methodology note, since a derived Season number can differ from a team's published one when the source is incomplete.
